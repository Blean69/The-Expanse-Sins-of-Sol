# Source and asset terms

Project-authored code and documentation use [PolyForm Noncommercial 1.0.0](../LICENSE), allowing personal noncommercial forks. This makes the source **source-available, not OSI open source**. The license does not cover borrowed material that the repository owner cannot license or third-party models, music, voices, game files or trademarks.

The [asset record](../ASSET-SOURCES.md) documents CC BY 4.0 attribution for some supplied models, including Tachi, Donnager and Truman. Other model sources have unspecified terms; OPA Dark Star and Munroe were purchased, but purchase alone does not establish redistribution terms. Supplied voice lines, soundtrack and PDC audio also lack documented public distribution grants. A free fan-project disclaimer does not settle their permissions.

The public alpha is being released at the project owner's request while these terms remain unresolved. Future releases should verify each source/license, keep required credit and modification notices, and obtain permission or replace assets where necessary. The separately prepared source-only snapshot omits generated meshes, textures, audio, packages and game binaries. The complete playable ZIP is a separate release artifact.
