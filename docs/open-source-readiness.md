# Source and asset terms

Project-authored code and documentation use [PolyForm Noncommercial 1.0.0](../LICENSE), allowing personal noncommercial forks. This makes the source **source-available, not OSI open source**. The license does not cover borrowed material that the repository owner cannot license or third-party models, music, voices, game files or trademarks.

The [asset record](../ASSET-SOURCES.md) documents known sources and credits, including CC BY 4.0 attribution for some supplied models. Other model, music, voice, sound and extracted-game-asset license details are not all recorded source by source in this repository. A free fan-project disclaimer is not a substitute for permission.

For 0.29.0, the project owner explicitly confirmed public redistribution rights for the included third-party assets. This is an owner representation, not an independent legal review or a source-by-source license inventory. Keep required credits and modification notices, and update the record as specific grants and terms are documented. The GitHub source tree omits generated meshes, textures, audio, packages and game binaries; the complete playable ZIP is a separate release artifact.
